# QB-EletronicBracelet
An eletronic bracelet for FiveM (Framework QBCore) Still in BETA, it uses qb-radialmenu and QB-Notify, soon there will be support for ox. For now it doesn't show the actual bracelet on the ankle.


Updated:

Bracelet Security Features
A cooldown for illegal removal attempts to prevent abuse.

Different bracelet tiers with various security levels.

Battery drains over time, requiring recharges.

Police receive alerts when an illegal removal is attempted.

Database & Optimization Enhancements
Improved database queries to be more efficient.

Better synchronization for bracelet status.

Optimized the way police receive updates to reduce server load.

Command Additions
/monitoringpanel → Opens the police monitoring UI.

/testbracelet [id] → Allows police/admins to apply a bracelet to a player for testing.
